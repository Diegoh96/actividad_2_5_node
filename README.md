# Actividad 2.5 - Node.js

## Descripción

Proyecto desarrollado en Node.js para practicar:

- Variables y tipos de datos
- Condicionales
- Ciclos
- Funciones
- Módulos
- Manejo de archivos con fs

Todos los ejercicios se ejecutan por consola usando Node.js.

## Requisitos

Tener instalado:

- Node.js
- Visual Studio Code

## Funcionalidades

### Variables y tipos
Muestra variables y sus tipos de datos por consola.

### Condicionales
Valida acceso según edad.

### Ciclos
Recorre un arreglo mostrando números pares.

### Funciones
Calcula IVA usando funciones.

### Módulos
Importación y exportación de funciones usando require y module.exports.

### Archivos fs
Crea y lee un archivo de texto usando fs.

## Ejecutar proyecto

1. Instalar Node.js

2. Abrir terminal en la carpeta del proyecto

3. Ejecutar en la terminal

npm init -y para crear el package.json

node node.js
